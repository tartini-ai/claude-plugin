# Measurement Plan guide (eval stand-in)

This short text stands in for Tartini AI's Measurement Plan guide in this plugin's evals only. The real guide, with the plan template, is on Tartini AI's server.

- Read the existing plans first. A new plan is one Markdown document written with draft_measurement_plan; it is saved at once from Claude Code.
- Build the plan on GA4's own events, Tartini Autocapture and the events the code already sends.
